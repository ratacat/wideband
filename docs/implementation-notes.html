Decisions

  • Use one batch Effect with provider completion events and per-flight replay/fanout. A cold stream would duplicate provider work across consumers.
  • Use native Effect.retry and Schedule for the single retry. Schedule metadata supplies attempt ordinals. The active-only cache has infinite capacity and zero settled retention, preventing eviction of pending searches and duplicate paid executions under a burst.
  • Keep ProviderAdapter, Sweep, Hit and Source. Distinguish each logical page/request from its transport attempts. RequestReceipt carries a typed result beside observed cost.
  • Persist a pending attempt before dispatch, finalize it during cancellation cleanup, and retain page hits before a later page fails. Unknown charges remain conservative reserved estimates with explicit uncertainty.
  • Engine.make returns an Effect. Ledger remains an internal synchronous SQLite resource owned by a scoped runtime layer. SQLite errors become typed LedgerError at that boundary.
  • SDK factory remains synchronous. Searches and snapshots return Promises, stream returns an AsyncIterable, close returns an idempotent Promise. Remove public Engine/Ledger handles in the 0.4 release.
  • Native Effect MCP was probed and rejected for this port. Its initialization behavior and extra capabilities added coupling. Retain the small custom boundary with strict schemas, real cancellation and awaited shutdown.
  • Keep Google durable proxy reservations and process-group cleanup. Use a native Effect callback whose finalizer kills and awaits close; standalone Promise exports run the effect only at their boundary.
  • Use finite Schema constraints, optionalKey and withDecodingDefaultKey for wire contracts. Effect value-level optional/default codecs otherwise emit nullable alternatives.
  • Normalize explicit undefined object properties at SDK parse boundaries. Keep null, nonfinite limits, and undefined array entries invalid. Accept null for optional descriptive provider metadata while retaining strict envelopes, URLs, and numeric fields.
  • Monthly usage is named attempts, while provider statistics use calls for settled provider operations. Legacy monthly attempt counts are approximate. No persisted table rename.
  • AnyAPI reserves its published 900-microdollar fallback bound and records the reported charge. Tavily models its published 8000-microdollar credit rate, doubled for research. Exa and Parallel include result surcharges.
  • Only effect 4.0.0 and Cheerio remain runtime dependencies. Zod and the unused platform-bun dependency were removed. The package version is 0.4.0, with Bun 1.4 as the tested minimum.
  • Do not add configuration settings, unit tests, comments, root folders, or additional worktrees. Replace obsolete unit tests with SDK/CLI/MCP E2E coverage and manual harnesses.

Evidence and limitations

Live searches succeeded for Brave, Exa, Desearch, AnyAPI, Tavily, Parallel, and Google. Other configured providers returned quota, rate-limit, server, or timeout failures. The live Google ledger was independently read and contains one completed sweep, two sources, and one settled zero-fee attempt at /var/folders/bs/bp3d31vs523_m1fxr5_46r9c0000gn/T/wideband-google-final-bdcs96z9.sqlite.

Storage fault checks prove a failed pending insert prevents dispatch, failed attempt finalization exposes observed cost while preserving a pending row, and failed summaries retain attempt charges. Forty concurrent legacy migration processes succeeded. The MI tool was run on old and new engine files; whole-file Visual Studio MI is zero for both, so no numerical maintainability improvement is claimed.
